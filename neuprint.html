neuPrint 查询执行台

在浏览器里直接执行 Cypher 查询，结果实时返回。数据源 neuprint.janelia.org，dataset male-cns:v1.0 （MaleCNS v1.0）。无需 token、无需安装任何东西。

✅ 为什么这个页面能直接取数据

neuPrint 的 API 开放了跨域访问（Access-Control-Allow-Origin: *）， 所以这个页面直接从你的浏览器请求官方服务器 —— 没有中间层、没有代理，你看到的就是官方返回的原始结果。 但它需要联网；断网时会显示连接失败。

⚠️ 两个字段名坑（踩过）

细胞类型字段是 type，不是 cellType —— 写错不报错，只返回 0 行。
连接关系是 ConnectsTo；upstream / downstream 只是节点上的计数字段，不能当关系查。
